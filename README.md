# BIG MART Frontend E-commerce

Pure HTML5 + CSS3 + Vanilla JavaScript supermarket website.

## Run
Open `index.html` directly in a browser.

## Demo accounts
- Admin: admin@bigmart.com / admin123
- User: user@bigmart.com / user123

## Notes
- Cart, wishlist, users, orders, addresses, notifications and theme use LocalStorage.
- Payment methods are frontend demo options only.
- No backend, framework, database or real payment gateway is included.
- Product visuals use emoji so the project works immediately without external image files.
